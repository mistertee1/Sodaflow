# تقرير D4.3.1 — أساس سياسات الاعتماد القابلة للضبط

## النتيجة

أضيف سجل محمي لسياسات اعتماد الخصومات والمصروفات ورديات العملاء والموردين. يستطيع المالك الفعلي فقط إنشاء السياسة أو تعديلها بعد إعادة تحقق حديثة، وتنتج دالة القرار دليلاً ثابتاً يربط النوع والقيمة وإصدار السياسة والدور المطلوب وهوية وسبب المعتمد.

## المنجز

- سياسات منفصلة للخصم والمصروف ورد العميل واسترداد المورد.
- الخصم يقاس كنسبة، وبقية السياسات تدعم SDG وUSD.
- مستويات من 1 إلى 10، متزايدة بلا تداخل، وآخر مستوى مفتوح فقط.
- منع سياستين نشطتين للنوع والعملة نفسيهما.
- optimistic revision لمنع تعديل إعداد قديم.
- صلاحيتا `approvals:read` و`approvals:manage`؛ الإدارة للمالك فقط والقراءة للمالك/المدير/المحاسب.
- حفظ السياسة داخل snapshot المرخص، مع استمرار منع الكتابة المباشرة عبر قواعد V2 العامة.
