## تنفيذ المصدر

- ResilientStore يحتفظ باسمه وواجهة استدعائه ويستخدم FirestoreStore فقط. فشل الاعتماد أو الصلاحية ينتقل إلى API503؛ لا replay إلى ملف ولا تغيير الاشتراك أو quota خارج المصدر. ملفات .data القديمة محفوظة دون قراءتها أو حذفها.
- 12 اختباراً جديداً للهوية/فشل commit/HTTP retry/السجل المحلي المزيف/Guest؛ 4 سيناريوهات تكامل حقيقي على Emulator `demo-sudaflow` لفشل التسجيل والتعافي والتعديل التجاري الذري والاشتراك المنتهي والحصة وصلاحية الإدارة الموقوفة.
- قبول Render عبر Docker وJava21 وChromium في مرحلة البناء. أولاً تشغيل اختبارات الحماية على النسخة السابقة لإثبات الفشل، ثم على الإصلاح. يشمل TypeScript وunit/API وbuild وEmulator وnpm audit وكل UI. فشل نطاق السوبر أدمن يمنع نشر تقرير القبول. فشل regression الواجهة يبقى مسجلاً وغير مقبول للدمج حتى لو نجح نطاق السوبر أدمن.
- الخدمة العامة تستضيف JSON لنتائج اصطناعية فقط؛ لا ERP/API أو منافذ Emulator أو أسرار أو معاملات حقيقية. autoDeploy معطل. الاختبارات لم تنفذ بعد؛ syntax check لسكربتات القبول فقط نجح محلياً.
