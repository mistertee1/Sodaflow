# تقرير C5.3.1 — واجهة سياسات الضرائب المحمية

الحالة: منفذة ومختبرة هندسياً في PR54، متراكمة فوق PR51. الدمج للمستخدم فقط، ولم يحدث نشر أو migration.

## المنفذ

- مركز ضرائب داخل واجهة المحاسبة يعرض سياسات المبيعات والمشتريات المسموح بها للمستخدم.
- القراءة متاحة للمالك والمحاسب عبر `tax:read`؛ الإنشاء والتعديل للمالك فقط عبر `tax:manage`.
- كل كتابة تتطلب إعادة تحقق المالك وسبباً مطابقاً للنموذج، وتحفظ إصداراً مدققاً جديداً.
- تحديث السياسة يستخدم `expected_revision` وقائمة بيضاء للحقول، ولا يعيد إرسال metadata الخادمية.
- حساب التحكم يرشح محاسبياً: التزام ضريبي دائن للمبيعات، وأصل آخر مدين للضريبة المستردة، أو تحميل المشتريات غير المستردة على التكلفة.
- حماية تبدل المؤسسة والجلسة، ومنع التنفيذ المزدوج، وإظهار الإصدار والسريان والحالة بعد إعادة التحميل.
