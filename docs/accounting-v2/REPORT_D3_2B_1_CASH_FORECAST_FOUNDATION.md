# تقرير D3.2b.1 — أساس توقع التدفقات النقدية

## المنجز
- محرك توقع نقدي حتمي يستمد التدفقات الداخلة من آجال أرصدة العملاء، والخارجة من آجال أرصدة الموردين.
- يعامل الرصيد المتأخر كتدفق في يوم الأساس، ويستبعد الاستحقاقات بعد نهاية الأفق، مع إجماليات مستقلة لـ SDG وUSD.
- تقرير محمي يتطلب محاسبة V2 وخطة فعالة وميزتي المحاسبة والتقارير المتقدمة وصلاحيات التقارير/العملاء/المدفوعات/الموردين.
- مسار API بلا cache ومرشحات مقيدة، وربط AppContext يحمي من تبدل المؤسسة أو الجلسة أثناء التحميل.
- لا يختلق مصروفات دورية أو مدفوعات مجدولة غير ممثلة بمصادر؛ تظهر تغطيتها `false` إلى حين تنفيذ سجل مصادرها.

## التحقق
- TypeScript وCore والبناء ناجحة محلياً.
- 344 اختبار وحدة/API ناجحة، وتشمل حساب الأفق والمتأخرات والاستبعاد والإجماليات والصلاحيات.
- CI `38435020579` ناجح على `9668483ad31192dbfff3a081a5712b409ca7df3d`: 344 وحدة/API، و35 Firestore Emulator، و68 UI regression، وصفر ثغرات production.
- لم يحدث نشر أو migration أو كتابة إنتاجية. قبول Render مستقل ومعلق لعدم وجود staging مطابق لهذا commit ومصادقة صالحة.
