# تقرير C5.2c — دورة الضريبة المتكاملة والمحميّة

الحالة: منفذة ومختبرة في PR53 فوق آخر PR51. الدمج والمراجعة للمستخدم فقط؛ لم يحدث نشر أو تعديل لقواعد Firebase أو بيانات إنتاج.

## ما تم تنفيذه

- دمج آخر تحديثات PR51 بدمج Git حقيقي ذي والدين، مع الاحتفاظ باختبار ضريبة الشراء الذي أضافه العمل المتزامن.
- ترحيل ضريبة المشتريات القابلة للاسترداد خارج تكلفة المخزون إلى أصل ضريبي مستقل، وتحميل غير القابلة للاسترداد على تكلفة المخزون.
- حفظ دليل سياسة الضريبة وإصدارها وبصمتها وتوزيع الأصل/الضريبة/إجمالي التزام المورد لكل بند وفي دفتري SDG وUSD.
- مردودات الشراء تعكس الضريبة القابلة للاسترداد المجمدة منفصلة عن WAC، ولا تنشئ أصلاً ضريبياً وهمياً للضريبة المرسملة.
- إشعارات المبيعات الدائنة والمردودات تعكس ضريبة وسياسة وحساب الفاتورة الأصليين حتى بعد تعديل النسبة الحية لاحقاً.
- دعم الخصومات العامة، الضريبة الشاملة والمضافة، فروق التقريب، الدولار، وحساب ضريبة مخصص دون فقد جزء من القيمة.
- الاستعادة تعيد بصمات سلسلة الضرائب المرتبطة بالمؤسسة الجديدة، وتتحقق من السلسلة والمراجع والمجاميع قبل أي كتابة.

- قبول Render الموثق على commit مطابق ومؤسسة اختبار اصطناعية ما زال مستقلاً ومعلقاً.
