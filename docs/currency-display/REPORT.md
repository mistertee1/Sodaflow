# توحيد عملة العرض

الحالة: تحت التنفيذ؛ لا ادعاء قبول أو نشر.

اعتمد المستخدم الخيار الأول مع إدخال سعر يدوي ثم تطبيقه. المطلوب عرض موحد في الشاشات والتقارير، مع بقاء الدفاتر والمستندات الأصلية دون ترحيل. المصدر مبني على PR130 مع حفظ main649ea3b وتخزين ملفات العملاء وتسعير الدولار. قبول PR130 لا يزال قيد CI عند بدء هذه المرحلة؛ إن تغير المصدر يعاد دمجه واختبار النتيجة.

المرحلة لا تفعّل Super Admin أو تغيّر بيانات إنتاج أو Rules أو أسرار. كل الاختبارات ببيانات اصطناعية.
