# تقرير Excel4.1d.1 — عقد أدلة المستندات التاريخية

## النتيجة

أضيف عقد تحقق خالص للقراءة يحدد الأدلة التي يجب اكتمالها قبل السماح بإنشاء فاتورة بيع أو شراء تاريخية أصلية. لا ينفذ العقد أي كتابة مالية.

## الضوابط

- يربط كل مستند بعميل أو مورد موجود، وبالحساب الرقابي الصحيح: 1200 للعملاء و2110 للموردين.
- يتحقق من تاريخ الاستحقاق وسعر صرف الدولار وصافي البنود والضريبة والإجمالي والمدفوع والمتبقي.
- يتطلب COGS تاريخياً مثبتاً لكل بند مخزون مباع، وقيمة مخزون أصلية مساوية لصافي بنود الشراء.
- الضريبة غير الصفرية تتطلب حساب ضريبة موجوداً وبصمة SHA-256 لإصدار إعداد الضريبة.
- أدلة السداد لا تسبق المستند، وتبقى مرتبة زمنياً، وتستخدم حسابات موجودة وسعر صرف موثق للدولار.
- يفشل العقد مغلقاً عند نقص الطرف أو COGS أو المخزون أو الضريبة أو السداد، ولا يحاول استنتاج التاريخ المالي.
