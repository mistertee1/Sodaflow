# Super Admin — حصر الدخول في حساب واحد، 13 أكتوبر 2026

## النتيجة الحالية

تم تنفيذ قفل حصري في الخادم وFirestore Rules عبر وثيقة محمية `platformAccess/superAdmin` تربط **UID والبريد المؤكد معاً**. يلزم كذلك claim Boolean صحيح وسجل `platformAdmins/{uid}` فعّال. الحساب المختلف يُرفض حتى إن كانت لديه claim وسجل فعّالان؛ لا يمنح إنشاء شركة أو Owner أي إدارة للمنصة.

اختبار الخادم المحلي والأنواع والبناء وaudit اعتماديات الإنتاج ناجح. قبول Emulator والواجهة قيد GitHub CI؛ لا تسجل المرحلة مكتملة قبل نجاحهما. لا تفعيل للحساب الحقيقي حتى هذه النقطة.

## التغييرات

- يعاد قراءة القفل داخل كل معاملة تجارية؛ تغييره أو تعطيله يمنع الحفظ من محرر مفتوح. القفل المفقود أو غير الصحيح يرفض الوصول ولا يختار أول مسجل تلقائياً.
- Bootstrap تقني يحل البريد عبر Firebase Admin SDK ويطابق UID والبريد والتحقق وعدم التعطيل. المعاينة لا تكتب؛ التطبيق يتطلب hash المعاينة الحالي ويرفض تغيّر الحالة أو إعادة إنشاء البريد بمعرّف آخر.
- السياسة وسجل الحساب وتعطيل سجلات الإدارة الأخرى وحدث audit واحد تُحفظ في معاملة واحدة. ثم تؤكد claim دون تغيير باقي claims. فشل claim يُبلغ بوضوح، وإعادة المعاينة تستأنف دون تكرار حدث أو سياسة.
- لا إنشاء حساب أو تغيير كلمة مرور أو تجاوز تحقق بريد داخل bootstrap. كلمات المرور وtokens ليست في المصدر أو fixtures أو التقارير أو إعدادات المتصفح.
- استعادة أمرَي الاختبارات من إدخالات package.json المكررة: الاتحاد الكامل دون تكرار أو تغيير dependency/lockfile؛ إصلاح فاصلة tsconfig.core.json المفقودة. هذا يحافظ على اختبارات المحاسبة التي كانت تُستبعد بصمت بسبب تكرار المفتاح.
- UI tests جديدة لحساب آخر يحمل claim وسجلاً فعّالاً، ولإغلاق السياسة أثناء فتح محرر؛ تُستخدم بيانات اصطناعية فقط.

## التفعيل بعد تجهيز الوصول

على بيئة تقنية موثوقة مع SUPER_ADMIN_EMAIL الخاص بالحساب المختار:

```bash
npm run billing:bootstrap -- --uid <verified-uid>
npm run billing:bootstrap -- --uid <verified-uid> --apply --review-hash <preview-hash>
```

يمكن حذف --uid في المعاينة فقط ليحل SDK البريد إلى UID؛ ثبّت UID الناتج عند التطبيق. لا تستخدم workflow الترحيل التجاري لمجرد ضبط حساب الإدارة قبل مراجعة نطاقه. نشر Rules يحتاج دمج جميع قواعد المحاسبة الحالية وتجديد fingerprint وفق إجراء التشغيل.
