# Excel4.2b.1 — سياسة التصدير المجدول

الأساس PR142 المقبول:596 وحدة/API و16 تشغيل و58 Emulator و137 واجهة على9e86c6a. هذا الفرع كان يحتوي checkpoint فقط دون المصدر المحلي الذي أشار إليه؛ انتهى حجزه10:56UTC، فأعيد الاستئناف من GitHub دون ادعاء بقاء الكود أو إعادة قبول قديم.

1. عقود نقية للجدول اليومي/الأسبوعي/الشهري في IANA timezone، مع نهاية الشهر والسنة الكبيسة والتوقيت الصيفي والفجوة/التكرار. الوقت المفقود ينتقل لأول دقيقة صالحة في اليوم، والتكرار يختار أول وقوع واحد. لا catch-up loop لمواعيد قديمة.
2. حقول مستخدم محدودة ومراجعة متوقعة للتحديث؛ metadata والمالك والمنشئ والموعد القادم والسجل لا يختارها العميل. يعاد إثبات صلاحيات مالية فعلية وبريد وعضوية واشتراك وميزات وV2 وسلطة الخادم، بلا اعتماد على تعطيل أزرار.
3. فترة التصدير مشتقة من موعد الجدول المحلي، ومعرف occurrence حتمي مربوط بالمؤسسة والجدول وإصداره واليوم المحلي لمنع تكرار DST. لا يحوّل حفظ الجدول أو استحقاقه إلى كتابة مالية.
4. احتفاظ محدود1–24 ساعة، ورابط تنزيل لا يتجاوز5 دقائق ولا انتهاء الملف؛ فحص الصلاحية والملكية والإصدار والحالة الحالية مطلوب عند التنزيل. لا رابط عام أو بيانات اتصال أو سر ضمن العقد.
5. اختبارات سلوكية للتقويم والصلاحيات والتغير قبل التشغيل/التنزيل والتلاعب بالحقول والمواعيد والحدود والمعرفات. هذه خطوة عقد فقط؛ ربط API/Firestore/claim/worker/download/UI مرحلة4.2b.2 قبل التشغيل.
