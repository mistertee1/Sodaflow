# تقرير D4.3.3 — واجهة سياسات وقرارات الاعتماد

## النتيجة

اكتملت واجهة إدارة سياسات اعتماد الخصومات والمصروفات ورد العميل واسترداد المورد، وربطت العمليات الأربع بعرض القرار المطلوب قبل الإرسال. تبقى بوابة الخادم الذرية من D4.3.2 هي السلطة النهائية، ولا تعتمد السلامة المالية على فحص الواجهة.

## الواجهة والصلاحيات

- مركز عربي لإنشاء السياسات وتعديلها وتفعيلها وإيقافها، مع مستويات متزايدة حسب النسبة أو SDG/USD.
- الإدارة متاحة للمالك فقط وتتطلب إعادة تحقق حديثة قبل كل حفظ؛ المدير والمحاسب يقرآن السياسات بلا أدوات تعديل، والمشاهد لا يرى المركز.
- الحفظ يستخدم الإصدار المتوقع ومعرف عملية مستقل، ويمنع الإرسال المكرر وتبدل المؤسسة أثناء الطلب.
- تظهر متطلبات السياسة داخل خصم الفاتورة والمصروف ورد العميل واسترداد المورد، مع الدور الأدنى وإصدار السياسة وسبب اعتماد إلزامي.
- تمنع الواجهة الإرسال عند نقص الدور، بينما يعيد الخادم اشتقاق القيمة والدور ويحفظ `approval_evidence` المجمّد.
- تتحدث القوائم فور نجاح الحفظ وتبقى السياسة بعد إعادة التحميل من snapshot المؤسسة.
