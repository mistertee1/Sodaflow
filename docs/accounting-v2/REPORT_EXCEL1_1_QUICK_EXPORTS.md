# تقرير Excel1.1 — التصدير السريع للبيانات الرئيسية

## النتيجة

اكتملت مرحلة Excel1.1 في الفرع `codex/accounting-v2-excel1-quick-exports-20261015` المبني على فرع E3 (PR #85)، وفتحت للمراجعة في PR #86. لا دمج، ولا auto-merge، ولا نشر أو migration.

## المنفذ

- مركز واجهة لتصدير العملاء والموردين والمنتجات والفواتير إلى مصنف Excel SpreadsheetML (`.xls`).
- خلايا رقمية فعلية للمبالغ والكميات والنسب، وأعمدة مستقلة لـ SDG وUSD ومعرّفات مستقرة مرتبة.
- النص الذي يبدأ بصيغة محتملة يبقى String ولا يتحول إلى Formula.
- صلاحيات مستقلة `export:*`: المالك/المدير/المحاسب لكل الوحدات؛ المبيعات للعملاء والفواتير فقط؛ لا تصدير للكاشير أو المشاهد.
- إخفاء الهاتف والبريد والعنوان والملاحظات الداخلية وتكلفة المنتجات/COGS عن المبيعات قبل التسلسل.
- حد آمن 2000 سجل و650KB، ورفض أي سجل تابع لمؤسسة أخرى.
- تدقيق `DATA_EXPORT_CREATED` يحفظ النوع والوحدة والعدد والحقول المحجوبة، مع idempotency وعدم تغيير المصدر.

- قبول Render مستقل ومعلّق؛ staging الحالي لا يطابق commit المرحلة، ولم يتم نشره أو استخدام بيانات عملاء.
