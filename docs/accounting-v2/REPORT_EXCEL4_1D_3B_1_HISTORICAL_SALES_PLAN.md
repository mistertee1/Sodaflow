# تقرير Excel4.1d.3b.1 — خطة المبيعات التاريخية الأصلية

## النتيجة

اكتملت طبقة تخطيط read-only لفواتير البيع التاريخية في PR #108، مكدسة فوق PR #107. تنتج الخطة المستندات والدفعات وحركات المخزون والقيود الحتمية قبل تمريرها إلى معاملة الكتابة الذرية اللاحقة.

- حساب دفاتر SDG وUSD من العملة الأصلية وأسعار الصرف المجمدة.
- فصل AR والإيراد والضريبة وCOGS والمخزون بقيود متوازنة.
- تخصيص القيمة الدفترية للتحصيلات المتتابعة وإثبات فروق العملة المحققة.
- تخطيط حركات المخزون بترتيب التاريخ والصف، مع منع الرصيد السالب.
- معرفات حتمية وكشف مسبق لتصادم المستندات والقيود والحركات وأرقام الفواتير.
- عدم تعديل المدخلات أو تنفيذ أي كتابة مالية.
