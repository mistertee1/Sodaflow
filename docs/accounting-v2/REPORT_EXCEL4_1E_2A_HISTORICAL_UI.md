# Excel4.1e.2a — واجهة المراجعة المحلية للمصنف التاريخي

2026-10-22 — PR119 تابع لفرع PR117؛ المستخدم وحده يراجع ويدمج.

## التنفيذ

تنزيل القالب الرسمي ورفع XLSX وقراءة الأدلة وعرض المستندات والبنود والدفعات وأخطاء التحقق. تتطلب الشاشة صلاحية import:accounting ومحاسبة V2. تبطل المراجعة عند تغير المؤسسة أو المستخدم أو revision؛ تُهمل النتائج المتأخرة. ظهر تبويب الاستيراد أيضاً لحامل صلاحية المحاسبة دون اشتراط صلاحيات استيراد البيانات الرئيسية.

## التحقق

TypeScript والبناء ناجحان، واختبارات القارئ 6/6 ناجحة. أضيف اختبار Playwright لتنزيل القالب ورفض ملف غير صالح وإثبات عدم تغيير التخزين المالي أو staging. تعذر تشغيله محلياً لغياب Chromium؛ محاولة التثبيت أعادت ملف ZIP ناقصاً. CI39840990009 على 11a8705f جارٍ ولم تُفترض نتيجته.

## الحدود والاستئناف

هذه واجهة مراجعة محلية فقط، بلا staging أو اعتماد مالي؛ Excel4.1e.2 غير مكتملة. يلزم إكمال اختبارات ملفات صحيحة وعزل السياق ثم ربط جلسة الخادم ومعاينة حديثة والاعتماد ببصمات الأدلة وسبب صريح واختبارات عدم الحفظ الجزئي. PR119 مسودة حتى التحقق. لم تتغير ملفات Super Admin أو المزامنة، ولم يحدث main merge أو نشر أو تغيير بيانات إنتاج. الوثيقة والجاهزية التجارية غير مكتملتين.

## متابعة إصلاح CI

فشل CI39841072085 بعد نجاح npm run check بسبب تنبيهات DOMPurify <=3.4.16؛ لم تعمل emulator/UI بسبب فشل التدقيق. تحديث محدود في package-lock فقط إلى 3.4.17 على 6462f863، دون تغيير بقية التبعيات أو ملفات الإيجنت الآخر. npm audit --omit=dev بعد التحديث: صفر ثغرات. CI39848463542 جارٍ؛ لا يُعد اختبار الواجهة ناجحاً حتى يثبت ذلك. بقي PR119 مسودة، والمرحلة جزئية. حُرر lease بعد حفظ نقطة الاستئناف.

## قبول الواجهة الأولي وتوسيع التغطية

نجح CI39848463542 على 6462f863 بما يشمل check والتدقيق وFirestore Emulator وPlaywright، وأثبت اختبار التنزيل/الملف المرفوض عدم الكتابة. أضيف على f5318cc5 اختبار ملف XLSX صحيح يعرض المرجع والدليل الأصلي، ثم يستبدل الملف بآخر مرفوض فيمسح المعاينة ويثبت تطابق التخزين قبل/بعد. CI لهذا الاختبار الإضافي مطلوب، ولا تُنسب إليه نتائج الرأس السابق. بقيت اختبارات تغير السياق وربط staging/الاعتماد قبل إكمال Excel4.1e.2.

## إغلاق Excel4.1e.2a

نجح CI39858718951 على 7e1a8580، ويشمل اختبار المصنف الصحيح وعرض الأدلة ومسح المعاينة عند استبدال الملف وإثبات عدم الكتابة. النتائج: 79 Excel/import، 381 وحدة/API، 35 Firestore Emulator، 94 Playwright، TypeScript/core/build وتدقيق الإنتاج صفر ثغرات. اكتملت خطوة المراجعة المحلية فقط؛ PR119 جاهز للمراجعة. التالي Excel4.1e.2b: staging الخادمي ومعاينة مرتبطة بالسياق واعتماد البصمات مع اختبارات عزل وتغير السياق وعدم الحفظ الجزئي. Excel4.1e.2 والوثيقة والجاهزية التجارية ليست مكتملة. التغييرات اللاحقة لهذا الرأس توثيق وتتبع فقط. لا دمج أو نشر أو تغييرات إنتاجية، وحُرر lease.
