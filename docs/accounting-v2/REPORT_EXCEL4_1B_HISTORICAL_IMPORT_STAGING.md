# تقرير Excel4.1b — staging المحمي للاستيراد التاريخي

## النتيجة

أضيف أمر خادمي محمي يشتق سياق التحقق من بيانات المؤسسة داخل المعاملة ثم يحفظ جلسة وstaging فقط. لا يعتمد مستندات أو قيوداً أو دفعات أو حركات مخزون.

## ضوابط السلامة

- صلاحية `import:accounting` محصورة في Owner وAdmin وAccountant، ويحجب Viewer.
- الحسابات والفترات والعملات والفروع والأبعاد والمراجع تُقرأ خادمياً ولا يقبلها الأمر من العميل.
- تحفظ بصمات SHA-256 مستقرة للسجلات وسياق التحقق.
- حد staging هو 620KB، والمراجع المكررة والفترات المغلقة أو غير المغطاة تفشل مغلقاً.
- الحزمة غير المتزنة تحفظ بحالة `staged_accounting_block` ولا تكون قابلة للاعتماد.
- يسجل `DATA_IMPORT_STARTED` نوع الملف والبصمة والصفوف والحالة.
