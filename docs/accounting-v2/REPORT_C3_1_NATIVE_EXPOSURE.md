# تقرير C3.1b — فصل عملة المصدر في إعادة التقييم

التاريخ: 2026-10-10. الفرع متراكب فوق PR38 ولا يتضمن أمر كتابة أو واجهة.

## المنفذ

- `fxRevaluationQuote` لم يعد يعيد تقييم إجمالي دفتر USD التقريري للحساب؛ يستخدم `nativeCurrencyExposure` ويفصل المصادر الأصلية SDG عن USD.
- الرصيد الأصلي بالدولار فقط يدخل هدف سعر الإقفال. الرصيد المحلي بالجنيه ومقابله التقريري بالدولار يظهران كقيم مستبعدة للمراجعة ولا يولدان ربحاً أو خسارة غير محققة.
- كل طرف نقدي مختار حتى تاريخ الإقفال يحتاج دليلاً واحداً لعملة المصدر. الطرف المفقود أو المكرر أو المرتبط بقيد/سطر خاطئ يفشل مغلقاً.
- مجموعة أدلة المصدر يمكن أن تغطي عدة حسابات؛ كل حساب يستهلك أطرافه فقط مع استمرار التحقق من صلاحية كل مؤشر قيد/سطر.

## الاختبارات

- 12/12 اختباراً متخصصاً نجحت محلياً، مع TypeScript/core ناجح.
- تغطية جديدة: ذمم SDG لها USD تقريري لا يعاد تقييمها، ذمم USD تعاد وحدها، AP سالب يرحل خسارة/ربح الاتجاه الصحيح، ودليل المصدر الناقص يفشل.
- CI الفعلي نجح: run 38054790708 — 273 وحدة/API، 33 Firestore Emulator، 50 واجهة regression، والأنواع/core/build وصفر ثغرات production.

## الحدود والخطوة التالية

- `native_source_allocations` ما زالت snapshot داخلية غير موصولة بعد بمحوّل خادمي يثبتها من الفواتير والمدفوعات والمشتريات والتسويات والافتتاحيات والحسابات النقدية. لذلك لا توجد صلاحية نشر أو أمر ترحيل في هذه المرحلة.
- التالي C3.1c: محولات مصدر خادمية fail-closed واختبارات تسويات جزئية/نهائية، ثم C3.2 للأمر الذري والعكس والمطابقة والنسخ الاحتياطي.
- لا تعديل بيانات تاريخية، لا Rules جديدة، لا migration، ولا قبول Render مدّعى.
