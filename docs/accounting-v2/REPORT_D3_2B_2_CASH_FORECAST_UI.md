# تقرير D3.2b.2 — واجهة توقع التدفقات النقدية

## المنجز
- تبويب محمي لتوقع النقد يظهر فقط مع صلاحيات التقارير المتقدمة وذمم الموردين.
- مرشحات تاريخ الأساس والأفق من يوم إلى 365 يوماً، مع تحميل تلقائي وتحديث صريح.
- بطاقات الداخل والخارج والصافي بالـSDG والـUSD، وجدول مرجعي لآجال العملاء والموردين.
- عرض واضح لحدود التغطية: المصروفات الدورية والمدفوعات المجدولة غير مشمولة قبل وجود سجلات مصادر موثقة.

- اختبارا UI للتحميل وحدود التغطية وإعادة التحميل، ولإخفاء التبويب عن المشاهد غير المخول.
