# C4.2 — دورة تسجيل الأصول وترحيل الإهلاك

## المنفذ

- أمر محمي وذري لتسجيل الأصل من قيد شراء موجود؛ لا يقبل تكلفة مشتقة من المتصفح.
- أمر إهلاك بالقسط المحدد في الجدول، مع قيد مدين لمصروف الإهلاك ودائن لمجمع الإهلاك في دفتري SDG وUSD.
- تحديث متسلسل لقيمة الأصل الدفترية ومجمع الإهلاك والحالة حتى اكتمال العمر الإنتاجي.
- صلاحية المالك والمحاسب فقط، مع فحص الاشتراك ومحاسبة V2 وسلطة الخادم والفترة المفتوحة قبل الكتابة.
- idempotency، مراجعة revision/sequence، منع المعرفات المتصادمة، ومنع الحقول والمبالغ والتواريخ المصطنعة.
- أدلة مصدر غير قابلة للتعديل ومطابقة مالية تقرأ فقط، مع عدادات ونسخ احتياطي واستعادة وتحويل tenant.

## التحقق

- الفحص المحلي الكامل ناجح: TypeScript وCore والبناء و293 اختبار وحدة/API.
- 4 اختبارات C4.2 متخصصة تغطي التسجيل والإهلاك مرة واحدة، الصلاحيات والفترات، التلاعب، rollback، والمطابقة والاستعادة.
- CI الفعلي ناجح على commit `ab2bc849b05bb36bd201d0d3c09f83adef28cbc8` في run `38108879973`.
- نجح 33 اختبار Firestore Emulator على `demo-sudaflow` و52 اختبار واجهة regression، وفحص تبعيات الإنتاج بنتيجة صفر ثغرات.

## النطاق والمخاطر المتبقية

- لا توجد واجهة مستخدم في هذه المرحلة، ولا نشر أو migration أو كتابة على بيانات إنتاجية.
- قبول Render مستقل ومعلّق حتى C4.3 لأن C4.2 غير مكشوفة للمستخدم النهائي.
- التالي C4.3: واجهة سجل الأصل والمعاينة والترحيل، الصلاحيات، المزامنة وإعادة التحميل ثم قبول Render.
- الفرع متراكم فوق PR44 ويلزم دمج السلسلة بالترتيب.
