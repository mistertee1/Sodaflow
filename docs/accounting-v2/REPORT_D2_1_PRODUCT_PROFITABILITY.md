# تقرير D2.1 — ربحية المنتجات المدعومة بالمصدر

## النطاق المنجز

- أضيف تقرير ربحية المنتجات للفترة بالـSDG والـUSD اعتماداً على الإيراد والتكلفة التاريخية المثبتين في الفاتورة والقيد.
- تُخصم الإشعارات الدائنة ومردودات المبيعات من المنتج الأصلي وفق التوزيعات غير القابلة للتبديل، وفي تاريخ مستند التصحيح.
- يعرض التقرير الكمية الصافية والمبيعات وCOGS ومجمل الربح والهامش والمخزون الحالي وقيمته ودورانه.
- يعاد بناء رصيد المخزون الافتتاحي والختامي من حركات القيمة؛ ويظل الدوران `null` عندما لا يتوفر مقام موثوق.
- لا تُعرض ربحية مكتملة عند غياب تكلفة تاريخية موثقة، ويفشل التقرير بصورة مغلقة عند فقد المنتج أو إثبات المصدر.
- أضيف API محمي وواجهة RTL مع حماية تبدل المؤسسة والجلسة، وصلاحيات `reports:advanced` و`products:read` وميزة `advanced_reports` وAccounting V2.
