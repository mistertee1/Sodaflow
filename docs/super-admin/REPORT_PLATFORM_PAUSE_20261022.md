## السلوك

- مفتاح إصدار واحد `src/config/platform-controls.json` بقيمة `enabled:false`؛ الخادم يحقنها في خدمات العمليات والمؤسسات والاشتراكات وإعادة المحاولة. لا تُقبل هذه القيمة من طلب المستخدم أو إعدادات الشركة.
- كل عضو حقيقي بدور معروف داخل شركته يحصل مؤقتاً على صلاحيات العمليات الكاملة؛ تعليق الشركة والعضوية والاشتراك وانتهاء الباقة وحصة 100 فاتورة وحدود المقاعد وميزات الباقة لا تمنع العمل في هذا الوضع.
- لا كتابة جماعية للأدوار أو تواريخ الاشتراكات: تبقى القيم الأصلية ومالك الشركة واحداً، ويستمر عد الاستخدام والسجل ومنع تكرار العمليات. سجل التدقيق يثبت الدور الأصلي والدور المؤثر مؤقتاً.
- كل مسارات `/api/super-admin` معطلة قبل قراءة قاعدة البيانات، ولو للحساب المعتمد. صفحة `/super-admin` تعرض التوقف المؤقت بلا تسجيل دخول إداري أو لوحة تجارية، وطلبات الترقية معطلة. كود اللوحة والباقات والأدوار والاختبارات الأصلية محفوظ.
- الواجهة تعتمد سياسة الخادم في snapshot، وتخفي قيود الباقات والترقية وتتيح وظائف الأعضاء، بما فيها الإعدادات والتحقق من هوية الحساب الحالي للعمليات الحساسة.
- Firestore Rules تقرأ نفس وضع الإصدار ببوابة صريحة مع فحص تطابقها وبصمتها في CI. تسمح قراءات الشركة لأعضائها الحقيقيين في الوضع المؤقت، وتبقى الكتابات المالية والعضويات والاشتراكات مباشرةً من العميل ممنوعة؛ العمليات تتم عبر API موثق ومعاملات Firestore فقط.
- تسجيل الدخول والبريد المؤكد وعزل الشركات والتحقق من المالك الفعلي ومنع الدور المزور وحماية المعاملات والأرصدة والإقفال وإعادة التحقق الحديثة باقية. العضوية المحذوفة أو غير المعروفة لا تنال صلاحيات. لا منح Super Admin للمستخدمين.

## النشر وإعادة التفعيل

الدمج بيد المستخدم. يلزم إصدار منسق للواجهة وAPI وRules وبصمتها؛ لا تكفي واجهة فقط. لا تستخدم workflow الترحيل التجاري القديم لإصدار هذا الوضع؛ لا ترحيل أو bootstrap مطلوب.

للعودة لاحقاً: `node scripts/platform-controls.mjs --enable` يحدث المفتاح وRules والبصمة في المصدر فقط؛ تراجع التغييرات وتختبر ثم تنشر API/واجهة وRules معاً. `--pause` يعيد الإيقاف. الأمر لا ينشر ولا يعدل قاعدة البيانات. تبقى الفواتير المحسوبة أثناء التوقف ضمن الاستخدام الأصلي، فلا تُعاد الحصة إلى الصفر عند إعادة التفعيل.

PR111 الآخر يخص فرع Render القديم؛ لم يُنسخ فوق main ولم يُعدّل فرعه. الملفات المالية والهوية والمزامنة الأصلية محفوظة، والتغييرات في نقاط الصلاحية فقط. لا أسرار أو مطالبات claims أو ترحيل أو نشر إنتاجي أو كتابة مالية فعلية ضمن هذا العمل.
