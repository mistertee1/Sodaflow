# C3.3 — واجهة إعادة تقييم العملات

## المنفذ

- معاينة خادمية `no-store` تقرأ الدفاتر والمصادر الفعلية ولا تقبل snapshot من المتصفح.
- بصمة SHA-256 للمعاينة نفسها تُرسل لأمر الترحيل، فيرفض الخادم أي تغير سابق للحفظ.
- واجهة عربية للمالك والمحاسب تحدد نهاية الفترة، سعر الإقفال، مصدر السعر، السبب والحسابات المختارة.
- عرض منفصل للرصيد الأصلي USD والقيمة الدفترية والهدف والتعديل، مع تأكيد صريح قبل الترحيل.
- حماية تغير المؤسسة/الجلسة والصلاحيات، منع الضغط المزدوج، operation ID ثابت لإعادة المحاولة، وسجل محفوظ بعد إعادة التحميل.
- المستخدمون دون صلاحيات الفترات لا يرون مسار إعادة التقييم.

## التحقق المحلي

- `npm run check`: ناجح، ويشمل TypeScript وCore و280 اختبار وحدة/API والبناء.
- اختبار C3.3 المالي المخصص: ناجح؛ المعاينة بلا كتابة، وبصمتها تطابق أمر الحفظ، والدور غير المصرح مرفوض.
- أضيف اختبارا Playwright للحفظ مرة واحدة وإعادة التحميل/الموبايل، ولحجب الدور غير المصرح.
- تشغيل Playwright المحلي تعذر لأن تنزيل Chromium أعاد ملفاً فارغاً/غير صالح؛ لا تسجل اختبارات الواجهة كناجحة قبل CI.

## النطاق والمخاطر المتبقية

- الفرع متراكم فوق PR41؛ لا دمج ولا نشر ولا migration.
- قبول Render مستقل ومعلّق حتى تتوفر خدمة Preview/Staging مطابقة للـcommit ومؤسسة اصطناعية.
- يجب أن يثبت CI اختبارات Emulator وكامل UI regression والاختبارين الجديدين قبل اعتبار المرحلة جاهزة للمراجعة.
