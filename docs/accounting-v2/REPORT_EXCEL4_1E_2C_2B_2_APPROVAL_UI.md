# Excel4.1e.2c.2b.2 — الموافقة الصريحة والاعتماد (قيد CI)

2026-10-23 — PR126 تابع لـPR124؛ المستخدم وحده يراجع ويدمج.

## المنفذ

تظهر موافقة checkbox بعد المعاينة الخادمية دون accounting_block، ويبقى زر الاعتماد معطلاً قبلها أو دون review_sha256 صالحة. جسر AppContext يرفض الضيف والمؤسسة المختلفة والبصمة الناقصة، ويرسل المدخلات المراجعة والبصمة ومعرف عملية المعاينة نفسه إلى historicalImport.commit. لا تنشئ الشاشة معرفاً مالياً جديداً عند retry.

عند 5xx أو 429 أو تغير جلسة غير محسوم يبقى الطلب المراجع في ذاكرة المكون ويظهر زر إعادة نفس الطلب، مع تعطيل تغيير الملف والمعاينة إلى أن يُحسم. أخطاء 4xx المحسومة تبطل الموافقة والمعاينة وتطلب مراجعة جديدة. الإيصال يتطلب مطابقة المؤسسة والجلسة وبصمة الصفوف، ويعرض accounting_block صراحة. الطلب والإيصال مربوطان بالهوية عند العرض، وتُرفض استجابة متأخرة تخص سياقاً غادره المستخدم.

## التحقق

نجح npm run check محلياً:84 Excel/import و382 وحدة/API وTypeScript/core والبناء، صفر فشل. إعادة فحص TypeScript النهائية بعد حارس هوية العرض ناجحة. أضيفت ثلاثة سيناريوهات Playwright: checkbox قبل الاعتماد،503 بعد الحفظ ثم نفس العملية مع فاتورة وتدقيق DATA_IMPORT_COMPLETED واحدين، تغير revision بين المعاينة والاعتماد بلا كتابة مالية، وتبديل المؤسسة أثناء تعليق رد الاعتماد ثم إطلاقه دون إيصال أو طلب معلق في المؤسسة الثانية. تستخدم Operations وMemoryStore معزولين، والمصادقة وRules verifier محاكاة، وليست قبول Firebase حي. CI واختبارات الواجهة الجديدة لم تُثبت بعد.

## الحدود والتالي

لا يُعلن اكتمال الجزء حتى CI. الطلب الكامل المعلق محفوظ في ذاكرة الشاشة فقط؛ بعد إعادة تحميلها يلزم مسار استعادة جلسة/إيصال آمن قبل ادعاء استئناف شامل عبر reload. يحتفظ sendCommand بمعرف retry دون حفظ payload مالي في التخزين المحلي. تبديل المؤسسة أو الخروج يمسح الحالة المحلية ولا يلغي طلباً قد وصل إلى الخادم؛ لا يُعرض نجاح في المؤسسة الجديدة. الربط الخادمي ما زال اختيارياً للأوامر القديمة، وإلزام العقد المراجع ومراجعة جلسات/إيصالات الاستيراد يبقيان مطلوبين قبل قبول الترحيل كله. بقية Excel4 وقبول Firebase الحي والوثيقة والجاهزية التجارية غير مكتملة. لا main write أو دمج أو نشر أو بيانات/قواعد إنتاج أو تعديل Super Admin/المزامنة.
