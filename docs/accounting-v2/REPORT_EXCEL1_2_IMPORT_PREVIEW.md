# تقرير Excel1.2 — القوالب وstaging والتحقق والمعاينة

## النتيجة

نُفّذت مرحلة Excel1.2 على الفرع `codex/accounting-v2-excel1-import-preview-20261015` المبني على فرع Excel1.1. المرحلة تنتهي عند القالب والرفع والربط والتحقق وكشف التكرار والمعاينة؛ لا تعتمد الصفوف ولا تكتب أي بيانات رئيسية أو مالية.

## المنفذ

- قوالب XLSX رسمية للعملاء والموردين والمنتجات، كل منها يحتوي `Instructions` و`Data` و`Examples` بعناوين ثابتة وأمثلة رقمية فعلية.
- قارئ XLSX بحدود 2MB و10 أوراق و40 عموداً و2000 صف، مع SHA-256 للملف ورفض صيغ Excel والنصوص الخطرة الشبيهة بالصيغ.
- ربط تلقائي للأعمدة بالمسميات والمرادفات العربية/الإنجليزية مع إمكانية مراجعة الربط يدوياً ومنع الربط المزدوج أو الحقول المجهولة.
- تطبيع المسافات والبريد والهاتف والعملات والأرقام والقيم المنطقية، وإظهار Auto-fix لكل قيمة تغيرت.
- أخطاء مانعة وتحذيرات مستقلة، وأرقام صفوف أصلية، وملخص للصفوف الصالحة والتحذيرات والأخطاء والتكرارات والتصحيحات.
- كشف التكرار داخل الملف وضد السجلات القائمة بمفاتيح الأعمال لا بالاسم وحده، وتحذير بصمة الملف المكررة.
- حظر الرصيد/الكمية/التكلفة الافتتاحية غير الصفرية وإحالتها إلى Excel2 حتى تمر عبر مصادر مالية وقيود ومطابقة.
- أمر خادمي idempotent يكتب فقط `import_sessions` و`import_staging` وحدث `DATA_IMPORT_STARTED`. لا يكتب في العملاء أو الموردين أو المنتجات، ولا توجد خطوة اعتماد في الواجهة.
- صلاحيات `import:*` للمالك والمدير والمحاسب فقط؛ المشاهد والمبيعات والكاشير لا يرون مركز الاستيراد ولا يستطيعون تنفيذ الأمر.

## الحدود والباقي

- هذه معاينة مؤقتة وليست تنفيذ import: لا توجد سياسة Skip/Update/Create قابلة للاعتماد، ولا commit job، ولا rollback.
- لا تشمل الأرصدة الافتتاحية أو المخزون الافتتاحي أو التكلفة أو المستندات التاريخية؛ هذه ضمن Excel2/Excel4 حسب وثيقة المتطلبات.
- لا تشمل saved presets أو سجل تاريخ كامل أو jobs كبيرة وملفات مؤقتة؛ هذه ضمن Excel3.
- قبول Render المصادق عليه مستقل ومعلق حتى وجود staging مطابق للـcommit، ولم يحدث نشر أو تعديل بيانات إنتاج.
- نقطة الاستئناف التالية هي Excel2.1: تصدير محاسبي ودفتر محاسب متطابق، على فرع تابع لـExcel1.2 إلى أن يدمج المستخدم الأساس.
