# تقرير Excel3.2c.2b — اعتماد الاستيراد الكبير والتراجع المحمي

## النتيجة

اكتمل مسار اعتماد السجلات التي اجتازت عامل التحقق ووصلت إلى `awaiting_commit`. الاعتماد ذري ومقيد بأدلة الجلسة وstaging وسياسة التكرار، ويولد نسخة احتياطية ودليل عملية يسمح بتراجع ذري ومحدود الصلاحية دون المساس بتعديلات لاحقة.

## ضوابط التنفيذ

- يعاد التحقق داخل المعاملة من المؤسسة، والجلسة، والبصمة، وإصدار المخطط، وعدد الصفوف، وحالة المهمة قبل أي كتابة.
- سياسة `skip` تتجاوز السجل الموجود، وسياسة `update` تحفظ حالته السابقة قبل الاستبدال؛ فساد السياسة يفشل مغلقاً.
- المعرفات حتمية، وربط batch/operation يمنع إعادة الاعتماد أو خلط أدلة مهمة أخرى.
- سقف الاعتماد الذري 400 صف؛ ما يتجاوزه يرفض دون كتابة جزئية.
- التراجع متاح للمالك أو المدير فقط، ويتطلب إعادة مصادقة حديثة وسبباً مدققاً.
- يرفض التراجع إذا تغير أي سجل بعد الاعتماد، ويعيد المحذوف والمحدث ويحذف المنشأ في معاملة واحدة.
- تعرض الواجهة الاعتماد عند `awaiting_commit` والتراجع المحمي، وتبقى النتيجة بعد المزامنة وإعادة التحميل.
