# تقرير B3.2a — تسلسل تصحيحات السعر والمردودات

تاريخ التقرير: 2026-10-07. **هذه نقطة تنفيذ للحسابات؛ B3 والعمليات الفعلية ما زالت غير مكتملة.**

## المنفذ

بدأ العمل من فرع B3.1 بعد مراجعة main وطلبات المحاسبة. يضيف `salesCorrectionState.ts` إعادة حساب سجل التصحيحات الثابت لبند المصدر قبل حساب التصحيح التالي:

- تصحيح السعر يستهلك قيمة الإيراد والضريبة فقط ويحافظ على كمية البضاعة وتكلفتها الأصلية.
- المردود الفعلي يستهلك كمية المصدر وتكلفته الأصلية، ويخفض الإيراد والضريبة المتبقيين بعد التصحيحات السابقة؛ لا يكرر التخفيض الأصلي بعد إشعار سعر دائن.
- بعد تصحيح السعر يبدأ أساس كمي جديد للقيمة المالية المتبقية؛ التوزيع التراكمي يحفظ فروقات التقريب عند آخر جزء، ويظل توزيع تكلفة المخزون مرتبطاً بالكمية والتكلفة الأصلية.
- مبلغ تصحيح السعر يطابق المبلغ المطلوب في العملة الأصلية، ويحفظ القيمة الدفترية المتبقية في الدفتر الآخر دون سعر صرف جديد.
- السجل يعاد حسابه حسب تسلسل متصل وتواريخ لا تسبق المصدر/التصحيح السابق. تكرار المعرف أو تغيير المصدر أو العملة أو المكونات أو القيمة المحفوظة يرفض العملية.
- بعد استهلاك كل القيمة المالية بتصحيح السعر يمكن إرجاع البضاعة مع استعادة تكلفتها فقط. المصدر ذو التكلفة المجهولة لا يجيز إعادة مخزون بتكلفة صفرية مختلقة.

`npm run check` نجح محلياً: فحص الأنواع والفحص الصارم و143 اختبار وحدة/API والبناء. أضيفت 8 اختبارات فوق اختبارات B3.1، تشمل تصحيح السعر قبل/بعد المردود، آخر جزء، استقلال تجزئة المردودات بين تصحيحات السعر، العملات، استهلاك القيمة بالكامل، التلاعب والتواريخ والحدود. أضيف تحقق من 48 تسلسلاً يجمع كميات كسرية وتصحيحات متعددة عند حدود الوحدات النقدية. طلب المراجعة: https://github.com/mistertee1/Sodaflow/pull/19. ## الباقي والحدود

لا يوجد أمر API أو زر ترحيل أو مجموعة مالية جديدة بعد. الدالة لا تحمل بيانات من Firestore ولا تمنح صلاحية: مصدر البند وسجل التصحيحات والعملة يجب تحميلها من معاملة المؤسسة في الخادم قبل استخدامها. الحد الحالي أقل من 1000 حدث سابق لكل بند؛ المسارات الأكبر تحتاج تنفيذ jobs مضبوطاً.

الخطوة التالية B3.2b هي حفظ إشعارات دائنة ومردودات وسندات استرداد ثابتة، وتحديث المخزون وAR/AP والعميل والقيد والتدقيق وidempotency في معاملة واحدة. يجب حساب الرصيد القابل للرد من الذمم الدائنة الفعلية؛ تخفيض فاتورة غير مسددة لا يجيز دفع قيمتها نقداً تلقائياً. يجب منع الإبطال بعد تصحيح/مردود، وربط التحصيل والتقارير التاريخية والمطابقة والنسخ الاحتياطي بالمصادر الجديدة. تظل حماية الباقة والدور والفترة وسلطة V2 والحسابات والأرصدة والسباقات مطلوبة على الخادم قبل أي ترحيل.

لم يتغير كود Super Admin أو المزامنة، ولم يحدث نشر أو تغيير قواعد Firebase أو بيانات إنتاج أو كتابة إلى main أو دمج. المستخدم وحده يراجع ويدمج. C وD وE وExcel 1–4 ما زالت مؤجلة بعد اكتمال B3.
