# تقرير Excel4.1a — أساس تحقق الاستيراد التاريخي

## النتيجة

أضيف عقد تحقق جاف للاستيراد التاريخي قبل staging أو أي كتابة. يغطي القيود والفواتير والمشتريات وميزان المراجعة القديم، ويعيد نتيجة صريحة تسمح بالانتقال إلى staging أو تفرض `accounting_block`.

## ضوابط السلامة

- القيود تحتاج طرفين على الأقل، حسابات موجودة، جهة واحدة لكل طرف، وتوازناً كاملاً.
- الفواتير والمشتريات تحتاج حساباً وطرفاً مقابلاً، ولا يجوز أن يتجاوز المدفوع الإجمالي.
- الفترات المقفلة والعملات والفروع والأبعاد غير المعتمدة أخطاء حاجبة.
- المراجع السابقة أو المكررة داخل الملف محجوبة.
- حجم التحقق من 1 إلى 5000 صف.
- الدالة لا تعدل المدخلات ولا تنشئ staging أو قيوداً أو مستندات.
