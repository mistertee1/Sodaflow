# تقرير C5.3.2 — تقارير الفترات الضريبية المحمية

الحالة: منفذة ومختبرة هندسياً في PR55، متراكمة فوق PR54. الدمج للمستخدم فقط، ولم يحدث نشر أو migration.

## المنفذ

- تقرير فترة ضريبية مصدره قيود دفتر الأستاذ في حسابات التحكم المعرّفة بالسياسات، وليس إعادة حساب قابلة للاختلاف من المستندات.
- رصيد افتتاحي، مدين ودائن الفترة، حركة صافية، ورصيد ختامي لكل حساب بالـSDG والـUSD.
- تجميع السياسات التي تشترك في حساب التحكم نفسه، لمنع مضاعفة الأرقام مع الاحتفاظ بالولايات ومعرفات السياسات.
- ملخص مستقل لضريبة المبيعات، ضريبة المشتريات المستردة، الالتزام، الأصل الضريبي، وصافي المستحق دون مقاصة بين العملتين.
- API بلا cache ومحمي بعضوية المؤسسة و`tax:read` والاشتراك النشط وAccounting V2.
- واجهة RTL لاختيار الفترة وعرض المصالحة؛ متاحة للمالك والمحاسب، مع حماية تبدل المؤسسة والجلسة وإعادة التحميل.

## الحدود والمخاطر المتبقية

- التقرير دفتر أستاذ ومصالحة داخلية، وليس إقراراً قانونياً أو محرك امتثال لدولة محددة.
- الضرائب غير القابلة للاسترداد تظل ضمن التكلفة ولا تظهر كأصل ضريبي، وفق السياسة المحفوظة.
- لا تمثل MemoryStore أو Emulator أو CI قبولاً منشوراً على Render.
- قبول Render معلق حتى تحديد staging مطابق للـcommit ومؤسسة اصطناعية معتمدة، دون بيانات عملاء.
