# تقرير C3.1 — أساس إعادة تقييم العملات في نهاية الفترة

الحالة: **أساس قراءة/حساب فقط؛ لا أمر كتابة ولا واجهة**.

## المنفذ

- `fxRevaluationQuote` يعيد تقييم حسابات النقدية وذمم العملاء والموردين ذات رصيد USD في آخر يوم للفترة فقط.
- سعر الإقفال ومصدره وسبب المراجعة إلزامية وصريحة؛ لا يجلب النظام سعراً ولا يستخدم السعر الافتراضي.
- يحسب الفرق في دفتر SDG مع إبقاء دفتر USD دون تغيير.
- حسابان مستقلان: `4210` أرباح غير محققة و`5510` خسائر غير محققة، دون خلطها مع realized FX.
- يرفض الحسابات غير النقدية، الرصيد الصفري، الحساب المقيم فعلياً، التكرار، الفترة المغلقة/المقفلة، الدليل الأجنبي أو الحسابات غير المحققة المعطلة.
- دالة الحساب نقية ولا تحفظ أو تمنح صلاحية أو تغلق فترة.
