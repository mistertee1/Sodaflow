# توحيد عملة العرض في سودافلو

الحالة: المصدر منفذ والفحص المحلي ناجح؛ قبول Emulator والمتصفح معلق حتى CI. لا ادعاء نشر إنتاج.

## السلوك

من إعدادات المؤسسة: اختر «عملة النظام والتعامل الافتراضية»، أدخل سعرها يدوياً لكل دولار وسعر الجنيه لكل دولار، ثم «تطبيق العملة والسعر». المسودة لا تؤثر في بقية التطبيق حتى نجاح الحفظ في Firebase؛ لا تخزين مالي محلي. تبقى عملة الدفاتر ودقتها الأصلية SDG/USD، والفواتير وسندات القبض وPDF/WhatsApp السابقة بعملتها وصرفها المجمد. الدولار يظل مرجع تسعير المنتجات.

الإعداد الواحد ينعكس في الرئيسية والمخزون وجرده والعملاء وقوائم الفواتير ومساحات العمل والمصروفات والمحاسبة وGL/AR/AP والنقدية والمطابقة والأصول والأرصدة الافتتاحية والمالك وإعادة التقييم والرسوم والتقارير. الأرقام المحولة من الدفترين تُوحّد عندما تتطابق، وتظهر مع اسم دفتر المصدر عند اختلافها؛ لا يُجمع الدفتران ولا تختفي أرصدة الجنيه ذات الدولار الصفري. حقول إدخال العمليات وسعر الصرف والمستند الأصلي تحتفظ بوحدتها الحقيقية وتعرض سياقها بوضوح.

CSV يحتفظ بالأعمدة الأصلية الدقيقة ويضيف مقابل العرض المسماة وسعره اليدوي؛ PDF التقارير يعرض العملة المختارة مع دفتر المصدر. PDF الفاتورة وسند القبض والمستندات الأصلية مستثناة من إعادة التحويل. أسعار المصدر الأجنبي المحفوظة تستخدم عند عرض تفاصيله.

## الحماية والتكامل

تحقق الخادم من العملة والأسعار الموجبة المحدودة والدقة وهوية الدولار=1 وتطابق سعر SDG، مع حفظ ذري في معاملة الإعدادات وصلاحياتها الحالية وتدقيقها. تحديث أسعار العملات الجزئي يحفظ أسعار العملات الأخرى في المعاملة ولا يطغى عليها. لم تعدل Security Rules أو صلاحيات المنصة أو Super Admin المتوقف.

الأساس main649ea3b مع PR128 المقبول للدولار وPR130 المقبول لمنع التكرار (568 اختباراً). ملفات استيراد Excel وcheckpoint وفرع الإيجينت الآخر لم تتغير. آخر مراجعة لتسليم PR126:74e6cc0،lease محرر؛ أي تعارض مباشر يترك دون تعديل وفق توجيه المستخدم. المستخدم يراجع ويدمج؛ لا كتابة main أو نشر أو أسرار أو معاملات إنتاج.
