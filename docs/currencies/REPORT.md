الجنيه السوداني والدولار محفوظان كما كانا، مع إكمال أسماء ورموز العملات الموجودة سابقاً في النوع، EUR وGBP. العملات الإضافية متاحة لتسعير فواتير المبيعات والتحصيل وتفضيلات العملاء. الإعداد الجديد هو «عملة التعامل الافتراضية» وليس تغيير وحدة الدفاتر القديمة.

1. افتح إعدادات المؤسسة واختر «عملة التعامل الافتراضية». للعملة الإضافية أدخل السعر المعتمد: `1 USD = …` من تلك العملة، مع إبقاء إعداد سعر الجنيه لكل دولار. لا توجد أسعار سوق تلقائية أو قيم مالية مفترضة.
2. الفواتير الجديدة تبدأ بهذه العملة. يمكن اختيار عملة فاتورة مختلفة وسعر خاص بها؛ تغيير عملة النموذج يصفّر أسعار البنود لمراجعتها. الفاتورة الأجنبية تستخدم عملة تسعير واحدة، مع بقاء الفواتير المزدوجة القديمة كما كانت.
3. يُحسب سعر البنود والخصم والضريبة والإجمالي في الخادم؛ لا تُقبل إجماليات الواجهة كسلطة مالية. تحفظ الفاتورة أصل التسعير و`currency_rates_used` وسياسة التقريب. تعديل الإعدادات لاحقاً لا يعيد تسعيرها.
4. التحصيل يقبل العملات المضافة ويحفظ سعره المستقل. سجل مصدر الفاتورة يعيد إثبات أصلها وكل تحصيل وتصحيح، ويحتفظ برصيد مستقل بعملة التسعير لتجنب ضياع جزء من الألف بعد دفعة جزئية. فرق التحويل بين القيمة التاريخية والتحصيل الحالي يظهر في حسابات فروق العملة القائمة.
5. قائمة الفواتير ومساحة تشغيل الفاتورة ورابط العميل وPDF والمعاينة ورسالة واتساب تعرض عملة الفاتورة وإجماليها والمتبقي وسعرها المحفوظ. سند القبض يعرض المبلغ المستلم وعملة التحصيل وسعرها المحفوظ. مسار مشاركة PDF الإلزامي القائم محفوظ.
6. تفضيل عملة العميل يغيّر مثال الهاتف ومفتاحه الافتراضي. يُحفظ الرقم الصحيح بصيغة دولية عند إدخاله؛ تغيير العملة لا يستبدل دولة رقم دولي موجود. الصيغ `+` و`00` والأرقام العربية والفارسية مدعومة. الرقم الفارغ أو غير القابل للتطبيع لا يُحوّل لرابط يرسل لشخص آخر؛ يفتح اختيار المستلم في واتساب.

## المعمارية والحدود

- `src/lib/currencyCatalog.ts` هو تعريف العملات والدقة والدولة والتطبيع المشترك لكل مسارات واتساب: الفاتورة، التذكير، الكشف وسند القبض.
- `default_transaction_currency` و`currency_rates` إعدادات مؤسسة محفوظة في Firebase عبر API. بيانات الأعمال لا تُحفظ في تخزين المتصفح أو ملف خادم محلي.
- لا يعاد تفسير الحقول التاريخية `_sdg` و`_usd`؛ تظل الدفاتر والتقارير المجمعة والحسابات المالية بالجنيه والدولار. النقد المحصل بعملة أخرى يحتفظ بأصل مبلغ التحصيل ويُرحّل بقيمته المحوّلة في الدفترين. هذه الإضافة لا تنشئ تلقائياً حسابات بنكية مستقلة بكل عملة.
- الإضافة تستهدف فواتير المبيعات والتحصيل والعملاء والمستندات. عقود المشتريات والمصروفات ورد النقد وإعدادات الضرائب المركزية القائمة تستمر بعملتي الدفاتر؛ لا تُعرض كأنها اكتسبت دفاتر عملات مستقلة. سياسة ضريبة مركزية لعملة إضافية تُرفض حالياً برسالة واضحة بدلاً من تطبيق ضريبة غير مدعومة.
- إعدادا العملة الأساسية والثانوية القديمان لا يسمحان باستبدال وحدة السجلات السابقة. لا ترحيل أو تعديل لأرصدة تاريخية، ولا تغيير للصلاحيات أو `firestore.rules` أو بصمتها. Super Admin وقيود الباقات متوقفة حسب PR116.
- استُعرض PR117 الخاص بورقة الاستيراد التاريخية وPR111 الخاص بجاهزية Firebase. لم تُنسخ ملفاتهما أو تُعدّل فروعهما. المستخدم يراجع ويدمج هذه المرحلة بنفسه؛ لا force push أو نشر إنتاجي تلقائي.

مرجع تعريف العملات: [SIX، الجهة المسؤولة عن ISO 4217](https://www.six-group.com/en/products-services/financial-information/market-reference-data/data-standards.html)، و[خطط ترقيم الدول من ITU](https://www.itu.int/ITU-T/inr/nnp/). دقة SDG القديمة بدون كسور محفوظة للتوافق مع الدفاتر الحالية.
