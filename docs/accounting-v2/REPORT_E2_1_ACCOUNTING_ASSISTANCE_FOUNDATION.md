# تقرير E2.1 — أساس مساعدة المحاسبة القابلة للمراجعة

## النتيجة

أُنجز أساس قرائي محمي يحوّل نتائج صحة المحاسبة إلى قائمة مهام مراجعة واضحة، ويضيف قواعد شذوذ حتمية، من دون إنشاء قيود أو مدفوعات أو تعديل بيانات مالية تاريخية.

## ما تغير

- تقرير `accounting-assistance` يربط كل مشكلة أو تنبيه من مركز الصحة بمسار المراجعة المناسب.
- قواعد حتمية لاستحقاق المورد خلال سبعة أيام، وهامش البيع السلبي من تكلفة مثبتة، والفترة المنتهية غير المقفلة.
- كل عنصر يحمل المصدر والإجراء المقترح ومسار المراجعة، ويثبت `manual_review` و`requires_confirmation`.
- API محمي بـ `no-store` ومرشح `asOf` صارم.
- الخادم يعيد التحقق من العضوية وصلاحيتي `reports:advanced` و`journal:read` والاشتراك وAccounting V2 وميزات الخطة.
