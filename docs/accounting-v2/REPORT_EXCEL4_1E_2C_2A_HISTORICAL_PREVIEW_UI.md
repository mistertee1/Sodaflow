# Excel4.1e.2c.2a — واجهة المعاينة الخادمية (قيد قبول CI)

2026-10-23 — PR123 تابع لـPR122؛ المستخدم وحده يراجع ويدمج.

## المنفذ

أضيف جسر AppContext إلى POST historical-import/preview مضبوط النوع، يتطلب حساباً مسجلاً ومؤسسة مطابقة ويرفض تغير epoch الجلسة أو مؤسسة الرد. لا يطبق proposed_changes على حالة العميل ولا يحفظ بيانات مالية.

زر المعاينة يعمل بعد حفظ جلسة staging، ويرسل بصمات الصفوف وسياق التحقق وأدلة المستندات المحفوظة. تعرض الشاشة عدد المستندات والقيود ونتائج المطابقة وتفاصيل القيود المقترحة بوصفها معاينة دون حفظ. النتيجة مربوطة بالجلسة ومعرف العملية ومدخلات الأدلة، وتُبطل عند تغير revision/الهوية أو استبدال المصنف؛ لا تُعرض استجابة متأخرة لسياق قديم. ما زال الاعتماد المالي غير متاح، ولا يعتد بحالة committed المقترحة كإيصال محفوظ.

## التحقق

نجح npm run check محلياً: TypeScript وlint:core و82 Excel/import و382 وحدة/API والبناء، صفر فشل. توسع اختبار Playwright المعزول لينفذ Operations الحقيقي للمعاينة على MemoryStore بسلطة server اختبارية، ويتطلب تطابق كامل المخزن قبل/بعد المعاينة وعرض مستند مقترح واحد ومسح النتيجة عند استبدال الملف. أضيف سيناريو تعليق رد المعاينة ثم تبديل المؤسسة وإطلاق الرد المتأخر دون إظهار الجلسة/المعاينة القديمة أو staging في المؤسسة الثانية. المصادقة وRules verifier محاكاة صريحة، وليست قبول Firebase حي. اختبارات الواجهة الجديدة وFirestore/التدقيق في CI لم تُثبت بعد؛ لا ادعاء نجاحها محلياً.

## الحدود والتالي

الجزء الحالي واجهة معاينة فقط، ويحتاج قبول CI وإصلاح أي إخفاق قبل إغلاقه. يتبع ذلك عقد اعتماد يربط بصمة الحالة والأثر المراجع والأدلة بالطلب المالي ويعيد التحقق داخل المعاملة، ثم اختبار نجاح/إعادة محاولة/تغير حالة وعزل السياق. لا تكتمل Excel4 أو الوثيقة أو الجاهزية التجارية؛ تبقى migration/auditor/scheduled exports وقبول Firebase السحابي المستقل. روجع main be2523e وفرع PR122 الأحدث، وحُفظت فروع العملات PR118 وSuper Admin/المزامنة دون استبدال أو دمج. لا main write أو نشر أو بيانات إنتاج أو نشر قواعد.
