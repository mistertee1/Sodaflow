# تقرير D3.1 — أساس الميزانيات وBudget vs Actual

## النتيجة

أُنجز أساس ميزانيات تشغيلي محمي في PR #65، متراكب على فرع D2.2. لا يتضمن هذا الجزء واجهة المستخدم أو Cash Forecast؛ وهما الخطوة D3.2.

## المنفذ

- سجل `budgets` خاص بالمؤسسة، بإصدار متزايد وoptimistic concurrency.
- بنود ميزانية لحسابات الإيراد والمصروف بمبالغ SDG وUSD وأبعاد اختيارية للفرع ومركز التكلفة والمشروع.
- تحقق من الحسابات والأبعاد النشطة، ومنع البنود المكررة والحقول المحمية والمدد غير الصحيحة.
- تقرير مصدره القيود الفعلية يعرض Budget وActual وVariance وVariance % خلال فترة الميزانية.
- صلاحيتان مستقلتان: `budget:read` و`budget:manage`. الإدارة للمالك والمدير، والقراءة للمحاسب والمشاهد أيضاً.
- القراءة المباشرة في Firestore مقيدة بالعضوية وميزة accounting، والكتابة المباشرة مرفوضة؛ الكتابة عبر الخادم فقط.
- API للقراءة: `GET /organizations/:orgId/reports/budget-vs-actual?budgetId=...`.
