# تقرير D4.1 — حدود ائتمان العملاء

## النطاق المنجز

- إضافة حد ائتمان مستقل بالجنيه السوداني والدولار لكل عميل، مع عدم فرض حد عند ترك القيمة فارغة.
- إضافة سياستين واضحتين: تحذير يسمح بالإصدار مع تجميد نتيجة التجاوز، أو اعتماد إلزامي يمنع الإصدار.
- حصر تعديل الحدود والسياسة في المالك والمدير.
- احتساب التعرض من الرصيد القائم زائد قيمة الفاتورة الجديدة في عملة الذمم الأصلية.
- منع ذري كامل عند تجاوز مستخدم غير مخول، دون رقم فاتورة أو حركة مخزون أو قيد أو سجل جزئي.
- إلزام المالك/المدير بسبب اعتماد غير فارغ، وتجميد الحد والرصيد والتعرض والهوية والسبب داخل الفاتورة.
