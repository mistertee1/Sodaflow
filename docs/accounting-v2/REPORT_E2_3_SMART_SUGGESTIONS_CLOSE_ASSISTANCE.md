# تقرير E2.3 — اقتراحات الحسابات ومساعدة الإقفال

## النتيجة

اكتملت مرحلة E2.3 كطبقة مساعدة قرائية قابلة للمراجعة. لا تغيّر أي حساب مثبت، ولا تنشئ قيداً، ولا تغلق فترة تلقائياً.

## المنجز

- اقتراح حساب مصروف من قاعدة تصنيف حتمية ودليل حسابات نشط من نوع مصروف تشغيلي.
- إظهار الحساب الحالي والمقترح ودرجة الثقة والمصدر، مع اشتراط المراجعة والتأكيد.
- تجاهل المصروفات الملغاة أو المستقبلية وعدم اقتراح حساب غير نشط أو غير متوافق.
- تشغيل قائمة الإقفال المحمية لأحدث فترة منتهية غير مقفلة.
- إظهار الفحوص غير المكتملة والفروقات والمطابقات الناقصة وهاش دفتر الفترة.
- إبقاء مراجعة فروق الصرف والتأكيد الصريح شرطين مستقلين قبل الإقفال.
- واجهة عربية قرائية فقط، مع صلاحيات ومزامنة وإعادة تحميل E2.2.

## الحدود والمخاطر

- الاقتراح الحتمي ليس حكماً محاسبياً؛ الحساب العام `5800` يبقى بدرجة ثقة تحتاج مراجعة.
- القائمة تعرض أحدث فترة منتهية غير مقفلة فقط، ولا تنفذ الإقفال.
- لا دمج ولا auto-merge ولا نشر ولا migration ولا كتابة إنتاجية.
- قبول Render مستقل ومعلق لأن staging المتاح لا يطابق commit هذه المرحلة.
