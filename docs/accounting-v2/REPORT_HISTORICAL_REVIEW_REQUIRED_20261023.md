# Excel4 — إلزام عقد المراجعة عند الاعتماد المالي

2026-10-23 — تابع لـPR138؛ المستخدم وحده يراجع ويدمج.

## النتيجة

كان expected_review_sha256 اختيارياً في الاستدعاء العام للاعتماد التاريخي. أصبح غيابه يعيد409 ورمز historical_review_required بعد التحقق من العضوية والصلاحية، وقبل قراءة إيصال سابق أو كتابة حد الطلبات أو مصدر مالي. تتطلب عملية الاعتماد خدمة الخادم؛ لا يوجد رجوع تلقائي إلى اعتماد قديم غير مراجع. يمكن إعادة معاينة الجلسة الحالية للحصول على طلب صالح.

أصبحت محاكاة الأثر للمعاينة قدرة داخلية بدالة JavaScript خاصة #executeCommand على محول المعاملة الذي لا يكتب. لا يستطيع العميل تفعيلها عبر previewOnly أو dry_run أو skip_review، ولا بإضافة وسيط إلى execute العام. تظل الخطة الداخلية والمعاينة قابلة للحساب دون بصمة اعتماد مسبقة، مع استمرار حواجز العضوية والإثبات الخادمي.

الطلب الصحيح يعيد إثبات بصمة الأدلة والحالة الحية في المعاملة نفسها قبل الالتزام. تبقى إعادة الطلب نفسه بنفس الفاعل ومعرف العملية والبصمة idempotent بعد الحواجز الحالية، ويسجل تدقيق الاعتماد review_sha256. لا يسمح غياب البصمة باسترجاع إيصال قديم عبر مسار الكتابة.

## التحقق

نجح npm run check محلياً:564 وحدة/API و16 Netlify runtime وTypeScript/core والبناء. ونجحت20 حالة historical import بعد إضافة حقل البصمة إلى التدقيق. تواصل الحالات الأصلية إثبات المعاينة دون استدعاء كتابة، والتحقق من أدلة المبيعات والمشتريات والضريبة والمخزون والاستعادة والمطابقة، ورفض الحالة أو النية المتغيرة، وإعادة المحاولة دون تكرار.

أضيف اختبار رفض الأمر القديم والأعلام المزورة والوسيط العام الإضافي، ورفض سلطة التخزين المحلية للاعتماد الفعلي، مع تطابق الحالة كاملة قبل الرفض وبعده. اختبار HTTP يستخدم createApi ومصادقة اصطناعية وMemoryStore معزولاً:409 للطلب القديم،400 للحقل المزور،403 للغريب، ومعاينة بلا كتابة، ثم طلب معتمد وإعادته ينتجان قيداً واحداً وحدث DATA_IMPORT_COMPLETED واحداً وبصمة تدقيق مطابقة.

CI الشامل لهذا المصدر، بما فيه Firestore وواجهة الاستيراد، مطلوب قبل اكتمال القبول. إثبات Rules والمصادقة في الاختبارات محاكاة؛ هذا ليس قبول Firebase حي.

## الحدود والتالي

استعادة الجلسة والإيصال بعد reload، وحزمة المراجع والتصدير المجدول وبقية Excel4، وقبول البيئة المصادق عليه وشروط المطابقة والاستعادة النهائية دون فروقات باقية. محضر مراجعة البرنامج لا يثبت أصالة ملف مالي خارجي مستقلاً. لا وصف تجاري جاهز ولا تفعيل إنتاجي أو نشر أو كتابة main أو دمج PR أو تغيير بيانات/قواعد إنتاج أو أموال حقيقية.
