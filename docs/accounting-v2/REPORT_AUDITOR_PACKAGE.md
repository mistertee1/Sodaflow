# حزمة المراجع Excel4.2a — 24 أكتوبر 2026

يتبع الفرع PR141 المقبول؛ المستخدم وحده يراجع ويدمج. التنفيذ مكتمل محلياً، وCI الكامل للمصدر الجديد مطلوب قبل قبول المرحلة.

## ما أصبح متاحاً

زر «تصدير حزمة المراجع» في مركز التصدير يجهز مصنف XLSX أصلياً للفترة المحددة. يتضمن14 ورقة: ميزان مفصل لكل حساب، الأستاذ العام بأرصدة افتتاحية وحركة وختام، رؤوس القيود وسطـورها، مراجع المصادر والجلسات التاريخية، التسويات، تاريخ الإغلاق المبدئي والنهائي وإعادة الفتح، حالة الفترات الحالية، مراجع التدقيق، نتائج المطابقة، أدلة النقد والبنوك المحفوظة، ملخص التصدير ودليل الحقول.

الأرقام خلايا Number منفصلة SDG/USD، ولا تُحوَّل العملة أو تُجمع الدفاتر. ميزان المراجعة يتبع الطبيعة الطبيعية للحساب، والأستاذ يعرض debit-positive مع line_index أصلي يبدأ من الصفر. الحركة للفترة المحددة؛ الافتتاحي من كل القيود السابقة. أحداث إغلاق/إعادة فتح فترة متداخلة تُدرج حتى لو نفذت بعد نهاية التقرير، ولا يُستنتج وضع تاريخي من وضع الفترة الحالي.

المطابقة تخص الحالة الحالية بكل التواريخ، وليست إعادة إنشاء دفتر قديم عند نهاية الفترة. تشمل فحص مصادر الدفتر والمخزون وAR/AP والنقد، وإثباتات hash لإغلاق الفترات وإصدارات الضرائب. الفروقات تُدرج بالأرقام والمعرفات والرسائل ولا تُستبدل بصفر؛ سلامة الأرقام وحدها لا تثبت سلامة hash. أدلة البنك/الصندوق موسومة محفوظة ولا تعني إجراء مطابقة جديدة. الدليل البنيوي الذي يمنع حساب دفتر صحيح، أو أرشيف التدقيق المتلاعب به، يرفض الملف دون اختراع تقرير فارغ.

## الحماية وعدم التكرار

الأمر `auditorExport.create` يتحقق خادمياً من البريد والعضوية وصلاحيات الدور الفعلي للتصدير والتدقيق والدفاتر والفترات والمصادر، وV2 والاشتراك وميزات accounting/advanced_reports/audit_trail قبل قراءة إيصال سابق. لا تمنح حالة توقف الضوابط التجارية دوراً غير مالي حق تنزيل حزمة تدقيق. حماية مصدر قواعد V2 الحالية باقية، بلا تعديل Rules أو مسارات المزامنة أو Super Admin.

تُقرأ المصادر في المعاملة نفسها بحد صريح5000 سجل و5MB بيانات و20000 سطر قيد و50000 صف مصنف، و600KB للملف المباشر. تُرفض الزيادة دون قطع صامت. النص الأطول من حد خلية Excel يرفض بدل اختصاره. تُكتب النصوص حرفياً، ولا Formula/Hyperlink أو بيانات اتصال/credentials أو حالات تدقيق before/after خام أو طلب اعتماد ضمن الحزمة. أرشيف التدقيق المستورد يُثبت بالـhash ويُظهر مؤسسة المصدر القديمة بوصفها provenance لا عضوية حالية.

يحفظ DATA_EXPORT_CREATED نوع الملف وعدده وحجمه وبصمة بايتاته وبصمة المصادر والفترة وعدد الفروقات. لا كتابة مالية؛ نفس معرّف الطلب وبصمته يعودان بملف العملية المؤكدة وتدقيق واحد. فشل التخزين لا يؤكد ملفاً ولا يترك تدقيقاً جزئياً. قفل النقر يمنع التحميل المزدوج، وإعادة محاولة رد ضائع تستخدم نية الخادم نفسها. تبديل المؤسسة لا ينزل الملف المتأخر في الجلسة الجديدة.

محرك ExcelJS يُحمَّل عند بناء الحزمة الخادمية، فلا يضيف حجمه إلى حزمة بدء التطبيق؛ أثبت البناء بقاء initial index نحو1.15MB بدلاً من2.10MB في المسودة الأولى. لا اعتماد جديد أو تغيير lockfile.
