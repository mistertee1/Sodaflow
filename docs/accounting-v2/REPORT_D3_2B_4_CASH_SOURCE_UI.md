# تقرير D3.2b.4 — واجهة إدارة مصادر التوقع النقدي

## المنجز

- نماذج إنشاء وتعديل المصروفات الدورية والمدفوعات المجدولة.
- دعم التكرار والحالات واتجاه الدفعات والمبالغ بالـSDG والـUSD والطرف والمرجع.
- مزامنة القائمة فور نجاح الحفظ مع حماية تبدل المؤسسة ومنع الإرسال المتكرر.
- وضع قراءة فقط لمن يملك `budget:read` دون `budget:manage`.
- تحديث التوقع يقرأ المصادر المحفوظة، مع بقاء البيانات تخطيطية بلا قيد أو دفعة فعلية.

## التحقق

- محلياً: TypeScript وCore والبناء و345 اختبار وحدة/API ناجحة.
- CI `38486656648` على `b0abf3ef03ab29dde6a94be66346c8f8d9acc294`: 345 وحدة/API، 35 Firestore Emulator، 72 UI، وصفر ثغرات production.
- اختبارات UI غطت الحفظ، الظهور في التوقع، إعادة التحميل، ووضع المحاسب للقراءة فقط.

## المخاطر وما بقي

- قبول Render مستقل ومعلق حتى نشر staging مطابق ومصادق عليه.
- لا حذف مادي للمصادر؛ الإيقاف/الإلغاء يحفظ التاريخ ويمنع دخول المصدر في التوقع.
- لا دمج أو نشر أو migration أو كتابة إنتاجية.
