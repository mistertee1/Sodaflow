المرجع المعتمد هو ملف PDF وحزمة ZIP اللذان أرفقهما المستخدم، مع طلب تطبيقهما كما هما بتاريخ 2026-10-01. قواعد هذا المرجع تحل محل المقترحات البصرية السابقة.

تمت مقارنة نص الدليل ونتيجة تصيير صفحاته الاثنتي عشرة مع الدليل داخل ZIP: جميع الصفحات متطابقة. ملفات الشعار الـ23 في `public/brand/logos` مطابقة بايتاً للأصول الأصلية، بما فيها SVG وPNG، دون إعادة رسم أو انعكاس في RTL. ملفات المعاينة في `public/brand/previews` من الحزمة نفسها. ملف `src/styles/sudaflow.tokens.json` مطابق للمرجع دون تعديل؛ الخط المحلي IBM Plex Sans Arabic بأوزان 400 و500 و600 مع تراخيصه داخل `public/brand`.

## التحقق

- `npm run check`: فحص TypeScript للواجهة والمحرك والخادم، 18 اختباراً للعمليات وواجهات API، وبناء الإنتاج.
- `npm run test:ui`: 8 اختبارات متصفح تغطي RTL والثيمين، العروض 320/390/768/1024، العمليات المالية، حالات الفاتورة، التركيز في الحوارات، وإعادة المحاولة بعد فشل الحفظ.
- تنزيل فاتورة من 60 بنداً: 5 صفحات، فُحصت بصرياً للتأكد من العربية، ترتيب سعر الصرف، اكتمال البنود، تكرار الرؤوس، الإجماليات وترقيم الصفحات.
- GitHub Actions يشغّل أيضاً 4 اختبارات لقواعد Firestore في مشروع محاكاة. نتيجة كل تشغيل مرتبطة بالتزامه في تبويب Actions.

هذا التغيير يخص العرض والمستندات والتفاعل؛ لا ينقل بيانات المنشآت، ولا يغير معادلات المحاسبة أو مفاتيح التخزين القديمة، ولا ينشر قواعد على قاعدة حية.

تحديث معتمد بطلب المستخدم بتاريخ 2026-10-01: نص شارة سعر الصرف المجمّد أبيض على خلفية Flow، وعلامة سودافلو المائية بالشعار الثنائي الأصلي أحادي اللون، بعتامة 7%، في الفواتير وسندات القبض ومعاينتها وطباعتها وتصديرها. تتكرر العلامة في كل صفحة PDF مع بقاء اسم وشعار المنشأة في رأس المستند.
