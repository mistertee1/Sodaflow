# تقرير C6 — القوائم المقارنة وضوابط الفترة

الحالة: منفذة ومختبرة هندسياً في PR56، متراكمة فوق PR55. الدمج للمستخدم فقط، ولم يحدث نشر أو migration.

## المنفذ

- API محمي يعيد القوائم الحالية وفترة مقارنة مستقلة في طلب واحد، مع رفض المرشحات غير المعروفة والفترات المعكوسة أو الناقصة.
- قائمة الدخل والتدفقات النقدية وميزان المراجعة تستخدم حركة كل فترة المختارة، بينما المركز المالي يبقى تراكمياً حتى تاريخ نهاية كل فترة.
- اختصارات: اليوم، هذا الأسبوع، هذا الشهر، الشهر الماضي، هذا الربع، وهذه السنة، مع بقاء النطاق المخصص متاحاً.
- اشتقاق فترة سابقة مساوية في عدد الأيام، وإمكان تعديلها أو إلغائها دون تغيير الفترة الحالية.
- ملخص RTL يقارن صافي الربح وإجمالي الأصول وصافي تغير النقد، مع توضيح ترتيب القيم وطبيعة المركز المالي حتى التاريخ.
- نفس الحساب متاح في وضع الضيف محلياً وفي السحابة عبر API، مع حماية العضوية وصلاحية `reports:advanced` والاشتراك والميزة الحالية.

- ملخص المقارنة يعرض SDG؛ تفاصيل كل قائمة ما زالت تعرض الدفاتر والعملات التي تدعمها مكونات التقارير الحالية.
- لا توجد رسوم اتجاهات أو جداول مقارنة سطرية لكل حساب في هذه المرحلة؛ الأرقام الكاملة متاحة لكل فترة من المحرك.

- قبول Render معلق حتى نشر commit مطابق واستخدام مؤسسة اصطناعية موثقة وجلسة مصرح بها؛ لم يحدث نشر في هذه الجولة.
