# تقرير E1.2 — واجهة مركز صحة المحاسبة والتنبيهات

## النتيجة

اكتملت واجهة قرائية لمركز صحة المحاسبة فوق أساس E1.1، مع صلاحيات ومزامنة وإعادة تحميل، من دون أي تصحيح تلقائي أو كتابة في القيود والسجلات المالية.

## ما تغير

- تبويب «صحة المحاسبة» متاح فقط لمن يملك `reports:advanced` و`journal:read`.
- تحميل التقرير تلقائياً من `Operations.accountingHealth` للضيف ومن API المحمي للسحابة.
- حارس يرفض نتيجة قديمة إذا تغيرت المؤسسة أو الجلسة أثناء الطلب.
- اختيار تاريخ الفحص وتحديث يدوي مع إعادة التحميل من المصدر.
- ملخص مستقل للمشكلات والتنبيهات والفحوص الناجحة والمتعثرة.
- بطاقات للفحوص وعناصر قابلة للمراجعة تعرض المصدر والتفصيل والإجراء المقترح.
- واجهة RTL متجاوبة على الهاتف ولا تمنح أي إجراء كتابة.

## الصلاحيات والسلوك

- Owner وAdmin وAccountant: رؤية المركز حسب خطة المؤسسة وعضوية الجلسة.
- Viewer وSales وCashier: لا يظهر لهم التبويب بسبب غياب صلاحية التقارير المتقدمة.
- الخادم يعيد التحقق من العضوية والاشتراك وAccounting V2 والميزتين `accounting` و`advanced_reports`.
